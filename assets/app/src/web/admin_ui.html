导入公众号数据

公众号后台 →「内容分析 / 图文分析」→ 导出数据，直接选择导出的 .xls 文件即可，无需另存为 CSV。推荐导「图文分析 → 单篇」（表头含「标题」）；「渠道日报」没有标题列，只能画趋势。
同时兼容 .xlsx、.csv、.tsv、UTF-16 / GBK 文本，以及「HTML 表格另存成 .xls」的伪 Excel。自动识别「阅读人数、分享人数、收藏人数、在看人数、日期、标题」等列，导出文件顶部的说明行会自动跳过。
这是绕开「数据统计接口未授权」的零成本方案，导入后「传播表现」视图立即显示真实图表。
导入结果是一次性快照，不会自动更新；个人订阅号无法申请微信认证，接口自动同步不可用。想更新时重新导出一次即可，不导入也不影响大屏的本地指标。
带标题的「单篇」导出会同步写入写作策略反馈台账，下一次定时任务据此调整选题、标题句式与话术；也可以直接把文件放进 ~/Downloads，效果相同。
单篇「数据明细（…）.xls」只补收藏 / 在看 / 点赞，按文件名里的标题逐篇配对；同一个文件重复导入会提示「已是最新」，不会覆盖其它文章的数据。
